# Paradox Siken v1.0

**Hearts of Iron 4 - Türkçe Hile Menüsü**

## Özellikler
- Tamamen Türkçe arayüz
- Lobi ve oyun içi hileler
- Kaynak düzenleme, birim güçlendirme
- Kolay kullanım (INSERT tuşu ile aç/kapat)
- Lisans sistemi ile güvenli erişim
- Otomatik güncelleme kontrolü

## Kullanım
1. `ParadoxSiken.exe` dosyasını **yönetici olarak** çalıştırın
2. Lisans anahtarınızı girin
3. Hearts of Iron 4'ü açın
4. Oyun içinde **INSERT** tuşuna basarak menüyü açın

## Gereksinimler
- Windows 10/11 (64-bit)
- Hearts of Iron 4 (Steam)
- İnternet bağlantısı (lisans doğrulama için)
- Antivirüs yazılımını geçici olarak kapatmanız gerekebilir
